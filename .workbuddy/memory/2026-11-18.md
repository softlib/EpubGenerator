# 2026-11-18

## EPUB 生成器项目（Delphi 12.2 + System.Zip）

- 完成 `EpubGenerator.pas`：可复用的 EPUB 3.0 生成器单元。支持元数据、多章节层级、封面、图片/音频/视频/字体/CSS、SMIL 媒体叠加、nav.xhtml + toc.ncx 双目录、`SaveToFile`/`SaveToStream`、占位符 `{{audio:id}}`/`{{video:id}}`/`{{image:id}}`/`{{link:id}}`。
- 关键规范点：`mimetype` 必须是 ZIP 第一个条目、`zcStored` 不压缩、extra field 长度为 0；章节位于 `OEBPS/Text/`，引用其他资源统一用 `../` 相对路径（需先剥离 `OEBPS/` 前缀）。
- 完成 `Demo/EpubDemo.dpr`、`BuildAndRun.bat`、CC0 测试素材（TestAssets/sample.mp3、sample.mp4、cover.png）与生成的 `Output/SampleBook.epub`；内置自检 21 项 + 独立 Python 结构校验全部通过。
- 编译方式：`C:\Program Files (x86)\Embarcadero\Studio\23.0\bin\dcc32.exe`（compiler 36.0）。Delphi 源码必须带 UTF-8 BOM，否则中文注释会被当作 ANSI 导致解析错误；Pascal `{ }` 注释内不能出现 `}}`（会提前结束注释）。
- 注意：`TTimeZone` 在 `System.DateUtils`，不是 `System.TimeZoneInfo`；类属性名 `Date` 会遮蔽同名全局函数。
